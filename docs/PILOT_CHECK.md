## Выполненные проверки

27 локальных тестов бизнес-правил, календаря и рендера прошли (`node --test tests/model.test.cjs tests/calendar.test.cjs tests/render.test.cjs`).

На опубликованном сервере через HTTPS API подтверждены:

- Вход и получение данных всеми четырьмя ролями; анонимный доступ запрещён; cookie сессии имеет Secure и HttpOnly.
- Фильтрация данных: менеджер и юрист не получают платежи, юрист видит только закреплённые дела и не получает снимок согласованной стоимости.
- Создание лида менеджером, переходы «Встреча» и «КП», передача координатору. Менеджер не может назначить стоимость.
- Координатор назначает сумму, но не утверждает её; открытие дела без одобрения запрещено.
- CEO возвращает сумму с обязательным комментарием; устаревшее решение отклоняется. Новая сумма аннулирует прежнее одобрение.
- Только координатор открывает дело; повторное открытие не создаёт дубль. Продажа становится успешной, снимок суммы сохраняется в деле.
- Назначенный юрист выполняет задачу, меняет статус дела, добавляет комментарий и отмечает документ в чек-листе. Чужое дело менять нельзя.
- Событие суда видит назначенный юрист, но не менеджер. Отмена события сохраняется.
- Начисление 110 000 ₸, поступления 30 000 ₸ и 80 000 ₸, остаток 0. Переплата и регистрация оплаты менеджером/юристом отклоняются.
- Дело завершено координатором; авторы действий сохранены. Юрист закрыть дело не может.
- Запись с устаревшей версией отклоняется с HTTP 409; запрос с чужим Origin — с HTTP 403.
- Выход каждой роли аннулирует созданную проверкой сессию.
